
# Quiz Application

A console-based multiple-choice quiz developed using Java.

## Features
- Multiple-choice questions
- Automatic answer checking
- Score and percentage calculation
- Performance feedback
- Immediate feedback for each answer

## Technologies
- Java
- Arrays
- Loops and conditional statements
- Scanner for user input

## Run Locally

```bash
javac QuizApplication.java
java QuizApplication
```

## Concepts Demonstrated
- Array-based data management
- Input validation
- Scoring logic
- Control flow

## Future Improvements
- Load questions from a database
- Add difficulty levels and categories
- Introduce a leaderboard
- Build a web version with Spring Boot
